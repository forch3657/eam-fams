# Gotchas

最高信号部分。按「现象 → 根因 → 处理」写；遇到新坑按同格式追加，不要把常识写进来。

## A. 契约与数据

1. **导出契约后某集合的字段悄悄少了，测试全绿**
   根因：字段曾手工补进后端契约 JSON，前端 schema 没有；导出把生成物恢复成 schema 内容。通用引擎丢弃未声明字段，不报错。
   处理：把字段补回 schema 再导出；核对 `git diff` 产物；补一条「导出后字段仍在」的断言用例。

2. **新加的枚举值后端报「取值不在枚举中」**
   根因：枚举真源与字典 seed / 契约产物只改了一处。
   处理：同源导出并在构建期做漂移检查；历史数据同步回填。

3. **某个字段前端显示已保存，刷新后为空**
   根因：字段名不在契约白名单，编解码层静默丢弃；或分类/部门落了中文名而非枚举码/主数据 id，被引用校验拒绝。
   处理：先查契约与导出 diff，再查提交载荷的字段类型，不要先改组件。

4. **导入报「缺少列」但表头看着没问题**
   根因：CSV 被 Excel 另存成 GBK，中文表头乱码、行数丢失；或文件缺 UTF-8 BOM。
   处理：用 UTF-8 BOM 模板，解析端剥离 `\uFEFF`；禁止 Excel 另存。

5. **全量业务建单直接 500，小批量正常**
   根因：明细 JSON 落在 `TEXT` 列，超过 64KB 上限。
   处理：迁到 `LONGTEXT`，脚本幂等。

## B. 状态、库存与事务

6. **审批动作返回 500，单据永久卡在「进行中」**
   根因：派生单据在主事务里创建，唯一键冲突触发 `UnexpectedRollbackException`，主流程被整体回滚。
   处理：派生改独立事务（`REQUIRES_NEW`），失败只回滚自身并写单据备注，不推翻终审结论。

7. **盘点单已完结，却既没有台账变化也没有派生单据**
   根因：明细存了中文分类/部门名、数量与金额为空，建账要素被契约校验拒绝；异常被 `catch` 吞掉只留一条 warn。
   处理：送审前置预检并点名到明细项；完结派生失败把失败件数与根因追加到备注；不静默兜底非法值。

8. **驳回或撤销后库存没恢复 / 被扣了两次**
   根因：状态迁移结算不幂等，或采用「填单即扣」跳过审批。
   处理：按 `DRAFT 不动 / PROCESSING 预占 / DONE 结算 / 终态释放` 三段实现，重复回调可重入。

9. **「我在途」列表出现已撤销单据，还显示「当前环节 / 待审批」**
   根因：把 `status !== 'DONE'` 当在途口径；终态单据没有清理审批信息展示。
   处理：用唯一的在途/终态常量；终态不计数、不显示当前环节、只留「查看详情」，要重办另开新单。

10. **三种撤销动作各自新增状态编码**
    根因：把动作类型当成单据状态。
    处理：统一落 `REVOKED`，动作差异写审批轨迹；改状态编码会牵动契约、字典和历史数据。

11. **有差异却没生成处置单**
    根因：审批条件 `hasDiff` 来自客户端 `ctx`；或差异判定读的是派生状态字段而非登记结果字段。
    处理：服务端按明细实际登记结果重算；统一判定字段。

12. **并发编辑互相覆盖，或偶发 500**
    根因：没有乐观锁或各接口策略不一致。
    处理：`version` 前置比对，冲突返 409 并给可读提示；明确「不带 version」的统一策略。

13. **单号重复撞唯一键**
    根因：前端推算单号；或生成规则精度不够。
    处理：服务端生成，含毫秒/随机后缀；名称备注按列宽截断。

## C. 权限与安全

14. **某个只读审批角色点开待办是空的，流程卡死**
    根因：审批人没有工作台待办权限，或读不到被审批对象（盘点单未随只读查看权限放开）。
    处理：检查角色是否同时具备「读被审计对象」与「待办」权限；mock 种子同样配齐。

15. **任意部门的人都能批别的部门的单据**
    根因：审批判定按「持有角色的任何人」而非按归属部门解析到人。
    处理：单据 deptId → 资产 deptId → 创建人部门；缺配置 400 点名环节，越权 403 点名到人。

16. **改了口令迁移逻辑后，全新部署无法登录**
    根因：用户列表响应做了脱敏，迁移逻辑误用已脱敏的查询，读不到口令字段。
    处理：内部迁移用未脱敏查询；写一条「全新部署首次登录」测试守住。

17. **接口无需登录即可重置任意账号密码 / 枚举用户 / 删除资产**
    根因：白名单放得太宽、后端零角色校验、前端 `isAuth` 只控按钮显示。
    处理：默认拒绝；每个写接口独立鉴权；白名单只留健康检查/版本/登录。

18. **验证码填错也能登录；登出后旧 token 仍可用**
    根因：验证码参数只在签名里接收从未校验；有状态 token 登出未删记录。
    处理：真校验 + 失败锁定；登出使 token 失效；被动登出别再调一次登出接口。

19. **引入了地图/人脸 SDK 但页面从没用过**
    根因：代码生成器模板残留。既拖慢首屏又暴露 Key。
    处理：全库搜组件标签，零调用即移除依赖与初始化代码。

## D. 构建与部署

20. **改完代码页面没变化 / 新接口 404 / 下载模板失败**
    根因：只跑 `mvn test` 或只跑前端构建，jar/dist 仍是旧的。
    处理：按 `stop → build → start` 重建；核对 jar 时间戳与 java 进程启动时间。

21. **`mvn clean package` 报 Failed to delete ...jar**
    根因：Windows 下运行中的 jar 锁住 `target`。
    处理：先停服务再打包。

22. **刷新两级路由白屏 / HTTPS 入口 403**
    根因：入口层缺 SPA 回退与 no-cache；后端未识别转发头。
    处理：`index.html` no-cache + 回退；`base:'/'`；回环监听 + `forward-headers-strategy: native`。

23. **长期 `-DskipTests` 后一次加固暴露多个变红测试类**
    根因：默认构建跳过测试，反馈环断裂。
    处理：唯一构建入口不允许跳过；CI 用 `verify` + 覆盖率阈值。

24. **测试库连到了生产库 / 应用账号执行 DDL 报 1142**
    根因：隔离配置没有「库不存在即启动失败」；应用账号只有 DML。
    处理：隔离环境显式校验库名；DDL 用单独管理员账号，口令不写仓库。

## E. 编码、环境与 E2E

25. **源码第 1 行非法字符 / Markdown 中文乱码**
    根因：Windows 下写文件产出 UTF-16LE（`FF FE`）。
    处理：写完核对头字节，转 UTF-8 再运行。

26. **`.ps1` 中文字符串乱码甚至脚本解析失败**
    根因：PowerShell 5.1 无 BOM 按 ANSI 读取。
    处理：`.ps1` 保持 ASCII-only；管理员 API 传中文按 UTF-8 字节发送；本地 SQL 脚本显式 `encoding: utf-8`。

27. **命令行找不到 node/npm**
    根因：预装运行时不在 PATH。
    处理：构建脚本自动探测预装版本目录并注入 `$env:Path`。

28. **E2E 断言「整页 403 就算通过」，越权没被发现**
    根因：负向断言太宽。
    处理：预期 4xx 精确到方法 + URL，并统计未预期 4xx = 0。

29. **E2E 清库后用例开始误报失败**
    根因：用例假设「台账里数据够多」或会改写生产数据却不还原。
    处理：体量自己造，改数据按执行前快照还原；临时数据只用 `E2E_` 前缀，`afterAll` 先用户后角色删除。

30. **Playwright 报告不更新 / 登录态跨 context 失效**
    根因：`--reporter=list` 覆盖 html reporter；token 存 `sessionStorage`。
    处理：去掉 reporter 覆盖；每用例走真实 UI 登录。

31. **自动点不到开关/下拉，读不到选中值**
    根因：Element Plus 组件结构。
    处理：点 `.el-switch` 包装元素；用 `.el-select` 的 `innerText` 读值；登录按钮文案含空格时用容错正则。

32. **E2E 脚本自动清空了业务数据**
    根因：把「清空重导」当成测试前置。
    处理：红线——清库是人工动作，脚本只清理自己创建的 `E2E_` 数据。
