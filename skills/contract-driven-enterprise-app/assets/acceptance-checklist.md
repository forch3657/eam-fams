# 后端交付验收清单

> 用法：后端交付时由交付方逐项打勾并附证据路径（测试报告 / 迁移脚本 / 截图），未勾选项列入遗留清单。

## 1. 契约

- [ ] 集合、字段、类型、可空性、枚举、引用关系在唯一真源 schema 中定义
- [ ] 契约产物由导出脚本生成，未被手工编辑；导出后 diff 已核对
- [ ] 新增字段同时覆盖：schema → 产物 → 迁移 SQL → 前端表单/表格 → 文档
- [ ] 权限码、枚举在构建期漂移检查中被覆盖
- [ ] 统一响应信封与错误码与文档一致（含 400/401/403/409/422 语义）
- [ ] 契约未声明字段的处理策略已写明（丢弃 / 拒绝）

## 2. 认证与权限

- [ ] 默认拒绝；匿名白名单仅含健康检查、版本、登录
- [ ] 口令加盐哈希存储，seed 明文口令在初始化时转换；全新部署首次登录可用
- [ ] 验证码真校验 + 失败锁定 + 口令有效期
- [ ] 登出后 token 确实失效；日志不输出 token / 口令
- [ ] 每个写接口独立做角色与数据范围校验（不依赖前端按钮隐藏）
- [ ] 多角色权限并集、停用角色排除、行级 dataScope 生效
- [ ] 只读审批角色能读到被审批对象且能看到待办
- [ ] 密钥本地生成并持久化到仓库外，未入库、未进前端

## 3. 状态机与审批

- [ ] 状态转换白名单；非草稿改 / 删返回 409
- [ ] 在途 / 终态口径由唯一常量定义；终态留痕、不计数、不可改删
- [ ] 撤销类动作统一终态编码，动作差异写入审批轨迹
- [ ] 审批人按归属部门解析；缺配置 400 点名环节，越权 403 点名到人
- [ ] 审批条件上下文服务端重算，不信任客户端传值
- [ ] 审批轨迹完整可查（含驳回、撤回、作废、加签、转办）
- [ ] 单号服务端生成；盘点/计划等关联约定前后端一致

## 4. 台账、库存与派生

- [ ] 草稿不动物品、提交预占、完结结算、驳回/撤销释放，且幂等
- [ ] 可用量 = 在库 − 预占；统计只算已完结，在途单列
- [ ] 台账状态仅由已完结单据驱动；主数据登记不被强制串审批
- [ ] 派生单据独立事务；失败不推翻主单据终审结论，失败件数写入备注
- [ ] 送审前置预检派生要素并点名到明细项
- [ ] 大明细列类型无 64KB 上限问题
- [ ] 迁移脚本幂等，同时处理 NULL 与空串历史数据

## 5. 并发与数据一致性

- [ ] 写操作前置 `version` 比对，冲突返 409 且提示可读
- [ ] 「不带 version」策略全局一致
- [ ] 值参数化、标识符来自契约白名单（无 SQL 注入面）
- [ ] 导入 CSV 为 UTF-8 BOM，解析端剥离 BOM；模板可下载
- [ ] 导入失败有行级错误报告，不产生半截数据

## 6. 构建、部署与验证

- [ ] 唯一构建入口串行执行后端打包 → 前端单测 → 漂移检查 → 前端构建；无跳过测试
- [ ] CI 分层与覆盖率阈值生效
- [ ] 契约变更按 schema → 导出 → 迁移 → 重建顺序执行过一次
- [ ] `stop → build → start` 后产物时间戳与进程启动时间一致
- [ ] 入口层 SPA 回退 + `index.html` no-cache；转发头配置正确
- [ ] 应用账号仅 DML；DDL 由管理员账号执行，口令未入仓库
- [ ] 隔离环境「库不存在即启动失败」，不会误连生产库
- [ ] E2E 分期按既定顺序跑通；报告 / trace / 截图路径可查
- [ ] E2E 只产生 `E2E_` 前缀数据并自清理；无自动清库代码
- [ ] 真实角色端到端旅程已走通（建单 → 送审 → 审批 → 完结 → 台账 → 报表）

## 7. 交付物

- [ ] 契约文档与验收清单、部署文档、缺陷台账、检查点报告
- [ ] 遗留问题清单（含责任人与计划）
- [ ] 用户手动点测入口与演示账号说明
