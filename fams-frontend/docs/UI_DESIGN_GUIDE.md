# UI 设计约束（看板 / 聚合页）

适用于工作台、经营看板等「一屏内呈现多块指标」的页面。目标只有一条：**数字可信、层级清晰、对齐严谨**。新增看板页直接复用本文规则，不要重新发明。

## 1. 字号阶梯

| Token | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 12px | 单位、chips、辅助说明、时间戳 —— **中文最小字号** |
| `--fs-sm` | 13px | 卡片内的次级标题、列表标题 |
| `--fs-base` | 14px | 正文、页签 |
| `--fs-md` | 16px | 区块标题 |
| `--fs-lg` | 20px | 次级指标数字 |
| `--fs-xl` | 24px | 页面主标题 |

- 11px 只允许用于非关键英文/数字，中文一律不低于 12px。
- 指标主数字用 22px（概览）或 18px（行动条），不再单列 token，靠字重与颜色建立层级。

## 2. 间距

- 基准 4px：`--sp-1` 4 / `--sp-2` 8 / `--sp-3` 12 / `--sp-4` 16 / `--sp-5` 20 / `--sp-6` 24。
- 卡片之间 12px，卡片内部纵向 12–16px，列之间 16px。
- 卡片内容左右缩进统一 `--content-px`（16px），概览列、行动条格、卡片头共用同一条左基线。

## 3. 颜色语义

| 语义 | 变量 | 说明 |
|---|---|---|
| 只读数据 / 金额 | `--c-data` | 中性深色。**不要用主色**，否则与可点击链接混淆 |
| 可操作 / 下钻 | `--c-action` | 主色，仅用于按钮、链接、非零待办数 |
| 风险 | `--c-risk` | 仅风险数量大于 0 时出现在数字上 |
| 健康 | `--c-health` | 无风险时给「正常」状态点，而不是显示一个灰 0 |

- 新增颜色一律走变量，并在 `[data-theme="dark"]` 中成对补值；禁止写死浅色底（如 `#f2f4f8`）。
- 分隔线用 `--bd`，1px 即可。不要用粗主色竖线做装饰。

## 4. 数字排版

- 所有指标数字加全局类 `.metric-num`：`--font-num` + `font-variant-numeric: tabular-nums`。
- 语序统一为「标签 + 值」：`总数 0`、`原值 ¥0`、`审批占用 0 件`。不要写 `0总数`。
- 货币符号比数字小一号（`.cur`），颜色用 `--t-sub`。
- 数量类指标必须带单位（件 / 台 / 单）。

## 5. 卡片结构

- 卡片头固定高度 `--card-hd-h`（44px），左右两列的卡片头必须等高，页签基线因此齐平。
- 卡片头左侧标题 13px / 600，右侧放计数或入口，同行两端对齐。
- 卡片标题必须与内容语义相符：含「我发起的 / 我已处理」的卡片不能叫「我的待办」，用「我的单据」。
- 卡片正文：`padding: 4px 16px 12px`，内容超出时卡片内部滚动，**不允许撑高页面**。

## 6. 指标分层

- 概览带（家底 / 时效）与行动条（待我审批 / 预警 / 我在途）职责分离，**同一指标不得在两处重复计数**。
- 概览由 `wm:overview` 控制：有权限显示完整家底，无权限（纯审批人）直接从行动条开始。
- 强调是条件式的：数量为 0 时不高亮，大于 0 才用主色底/警示色。

## 7. 空态

- 空态在容器内垂直居中，不用顶部对齐留出大片空白。
- 必须有**一个**可执行的主动作（查看台账、查看库存等），不能只有一句说明。
- 排障类长说明（「为什么我没有待办？」）收进 `el-collapse`，默认收起。
- 插画尺寸 60，三处空态文案要有区分，不要复用同一句。

## 8. 响应式

| 断点 | 行为 |
|---|---|
| `max-height: 720px` | 隐藏空态插画、卡片头 36px、指标数字降一档、chips 单行截断 |
| `max-width: 1280px` | 概览三列降为两列，第三组跨列并加顶部分隔线 |

任何断点下都不能产生整页纵向滚动；超出内容在卡片内部滚动。

## 9. 交互反馈

- 整块区域可点击时，hover 给淡底（`--bg-hover`）+ 右侧箭头，过渡 0.15s。
- 不可点击的元素不要给 `cursor: pointer`。
- 低频辅助操作（刷新等）用无边框图标按钮 + tooltip，不占页头主位。

## 10. 交付前检查

1. 真实数据下数字不换行、列宽不跳动（tabular-nums）。
2. 浅色/深色两套主题下 chips、hover 底、分隔线均正常。
3. 矮屏（约 700px 高）与窄屏（<1280px）各看一次，无裁切、无整页滚动。
4. `npm run build` 与 `npm test` 通过。
